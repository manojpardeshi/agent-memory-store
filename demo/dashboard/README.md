# Memory Handoff Lab

A local dashboard that replays the measured Claude → GPT → local Llama provider matrix and shows exactly how much memory entered each receiving prompt.

## Run locally

```bash
cd demo/dashboard
npm install
npm run dev
```

Open the printed local URL. The dashboard starts with the committed cross-provider live evidence report. Use **Load report** to inspect schema-v2 or schema-v3 evidence generated by:

```bash
.venv/bin/python -m demo.provider_matrix --mode live --json
```

The committed report includes `llama3.1:8b` through the loopback Ollama JSON API. Select another installed Ollama model with `--include-local --local-provider ollama --local-model MODEL`.

Imported reports stay in browser memory. The dashboard does not upload a report, open the SQLite database, or call a hosted model.
