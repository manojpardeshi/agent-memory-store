# Support

LLM Memory Store is a community open-source project maintained on a best-effort basis. It provides no
warranty, uptime promise, response-time commitment, managed service, or private production support.

## Getting help

- Read `README.md` and the architecture contracts first.
- Search existing GitHub issues before opening a new one.
- Use a public issue for reproducible bugs, documentation problems, and bounded feature proposals.
- Follow `SECURITY.md` for suspected vulnerabilities.

Public reports must use synthetic content. Never post a memory database, export, backup, prompt,
credential, model cache, local filesystem path, or other personal artifact.

## Supported scope

Support covers the latest published `0.1.x` release on the Python versions and platforms for which
that release records clean-install evidence. The declared package floor is Python 3.11. Local model
runtimes, model downloads, operating-system encryption, downstream applications, and third-party MCP
hosts remain independently operated components.

Questions that require a network service, multiple human users, organization authorization, managed
operations, or forensic deletion are outside the current product boundary.
