# LLM Memory Store 0.1.0

LLM Memory Store 0.1.0 is the first public release candidate of a personal, local-first memory layer
for LLM applications and agents. It provides a Python API, CLI, and MCP stdio server backed by SQLite
and local embeddings, without a network listener or always-on daemon.

## Highlights

- Typed facts, preferences, summaries, events, and expiring raw turns.
- Exact private scopes and explicitly selected shared pools.
- Local semantic recall with identity-scoped relevance filtering and versioned quality evidence.
- Versioned correction, provenance, previewed hard deletion, and safe expiry purge.
- Owner-only JSON export, SQLite backup/restore, JSON import, and embedding migration workflows.
- Review-first local extraction proposals with source revalidation and explicit selected acceptance.
- Runnable Python/MCP application starter and provider-neutral synthetic handoff demonstrations.

## Safety and privacy boundaries

- The local OS account, filesystem permissions, and full-disk encryption are the security boundary.
- Recalled memory and model output remain untrusted data; models receive no automatic write authority.
- Automatic extraction acceptance is not enabled. Every measured live local extractor remained below
  the frozen automation thresholds.
- Verified deletion removes data from the active database, not from prior backups, snapshots, synced
  copies, model-provider systems, or storage-media remnants.
- MCP uses stdio only. Remote/multi-user authorization and managed service operation are out of scope.

## Packaging

The package requires Python 3.11 or newer. The release candidate wheel completed the synthetic offline
lifecycle on Python 3.11, 3.12, 3.13, and 3.14. FastEmbed downloads the configured embedding model on
first use; subsequent operation can remain local when the model cache is available. Deterministic
tests and smoke checks require no model download.

The project is licensed under Apache-2.0. Codeberg is the canonical source and issue tracker; PyPI is
the Python distribution channel.

## Known limitations

- The product boundary is one trusted local human user and a handful of applications or agents.
- `sqlite-vec` remains pre-1.0 and is isolated behind the store API.
- Certified default relevance filtering applies only to the recorded behavioral identities.
- Extraction quality is suitable for human review, not unattended durable-memory writes.
- No semantic contradiction judge, background scheduler, HTTP server, or document-ingestion system is
  included.
