# LLM Memory Store 0.3.0

LLM Memory Store 0.3.0 adds `occurred_at`, so a memory can record when its source happened as well
as when it was stored. The release also moves the project's home to GitHub and publishes the
completed comparison with Supermemory Local. Memories stored without `occurred_at` rank and render
exactly as in 0.2.

## Highlights

- **`occurred_at`.** `remember`, `remember_turn`, `llm-memory remember[-turn] --occurred-at`, and
  the MCP remember tools accept the time a memory's source happened. Imported history then ranks
  as old rather than new, and context headers show the real date to the model.
  - Recall recency uses it.
  - Corrections keep it.
  - Expiry still counts from storage, so imported turns are not purged on arrival.
  - It must be ISO 8601 with a timezone and not in the future (five minutes of clock skew are
    tolerated). It is stored in UTC.
- **New home.** The canonical repository is now
  `https://github.com/manojpardeshi/agent-memory-store`, and the package metadata points there.
  Codeberg's Terms of Use now prohibit projects mostly written with generative-AI tools, which
  describes this one.

## Compatibility

- The first writable open adds a nullable `occurred_at` column. `SCHEMA_VERSION` stays 1, and no
  stored data is rewritten.
- Read-only opens of older stores keep working without the column.
- 0.1.0 and 0.2.0 from PyPI keep reading and writing an upgraded store. A correction made by those
  older runtimes does not carry `occurred_at` forward.
- JSON export gains an optional `occurred_at` field. Importers from before 0.3 ignore it, and 0.3
  imports exports that lack it.

## Measured evidence

On all sixty stratified LongMemEval-S questions, under free local models, the store's top ten
contained the gold answer text in 35 cases. Supermemory Local 0.0.8's top ten contained it in 15
(every discordant question went to the store, p = 1.9 × 10⁻⁶), and its full default output, at
about four times the store's context, in 22. A check that also requires the answer's numbers
leaves the store at 35 and Supermemory's full output at 17 (20–2, p = 0.0001). That check also
showed an earlier apparent Supermemory lead on temporal questions to be a metric artifact. The
full record is in `docs/architecture/benchmarks/2026-10-18-supermemory-local-strat60.md`.
